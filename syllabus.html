Detailed Syllabus

Each track is organized into modules that can be expanded below. The modules are presented in a practical sequence, moving from foundations to implementation and then to independent projects.

Non-Technical Syllabus Best for business users, founders, operators, marketers, and anyone who wants to use AI intelligently.
Typical duration 12 weeks, with flexibility based on learner pace
Module 1: AI fundamentals, ecosystem, and economics

Learners start with a plain-language introduction to AI and machine learning, then move into how AI tools work in real business settings. The focus is on understanding what models can and cannot do, how context windows affect output, and how usage costs are created.

  • Core AI and ML concepts explained clearly
  • Generative AI trends and real-world use cases
  • Applications in marketing, HR, customer service, and operations
  • Tokens, rate limits, and cost awareness
  • Prompt-based assistants and local inference basics
  • How LLMs differ from search engines and traditional software
Module 2: Prompting and structured AI communication

Students learn to write prompts that produce reliable and structured results. The goal is to turn a chatbot into a useful assistant that can generate consistent, machine-readable outputs.

  • Zero-shot, one-shot, and few-shot prompting
  • System prompts and role-based behavior
  • JSON outputs, tables, and structured responses
  • Prompt strategies for more reliable outputs and fewer hallucinations
  • Prompt tuning for higher reliability
Module 3: No-code automation and workflow design

This module teaches learners how to connect tools and automate repetitive work using no-code or low-code platforms. Learners also gain an intuitive understanding of APIs, webhooks, and data movement between applications.

  • Zapier, Make, n8n, Airtable, Bubble, and related tools
  • Webhooks, REST APIs, and JSON data handling
  • Workflow planning and automation architecture
  • Business applications such as email routing, spreadsheet analysis, and CRM updates
  • AI-driven content generation, lead qualification, and support routing
Module 4: Local AI, privacy, and document analysis

Learners are introduced to local model usage for privacy-sensitive work. The training explains how to choose model sizes, understand hardware constraints, and use local tools to analyze files without sending data to external APIs.

  • Local AI tools such as LM Studio and Ollama
  • Model selection and quantization concepts
  • Offline document chat and retrieval workflows
  • Privacy-first usage for sensitive files and internal work
  • When to use local models versus cloud tools
Module 5: Agentic systems and AI strategy

The final module moves beyond single-step workflows and into multi-step or multi-agent systems. Learners design AI processes that can plan, retrieve information, and complete tasks with minimal manual intervention.

  • Agent workflows and multi-step automation
  • Enterprise AI adoption and governance basics
  • Risk awareness, trust, and safety
  • Human-in-the-loop review and change management
  • Business transformation with AI
Technical Syllabus Best for developers, engineers, analysts, and technical learners who want to build AI systems.
Typical duration 16 weeks, with depth adjusted to learner ability
Module 1: Python, math foundations, and deep learning basics

The technical path starts with a focused review of the math and Python foundation needed for AI development. Learners revisit the core principles that support modern machine learning and deep learning systems.

  • Python, NumPy, and data handling essentials
  • Pandas, data preparation, and exploratory analysis
  • Linear algebra, calculus, and probability fundamentals
  • Supervised learning and model evaluation
  • Linear regression, logistic regression, trees, and ensembles
  • Neural networks and backpropagation
Module 2: API orchestration and structured prompting

Learners build robust AI integrations using commercial model APIs. The emphasis is on reliability, retry logic, structured outputs, and clean software integration.

  • OpenAI and Anthropic API usage
  • Retry logic, batching, and async patterns
  • Function calling and JSON schema design
  • Structured tool execution and deterministic downstream workflows
  • Prompt templating and tool integration
Module 3: RAG, embeddings, and vector databases

This module covers retrieval-augmented generation from architecture to implementation. Learners create systems that pull in relevant context from their own data before generating answers.

  • Embeddings and semantic similarity
  • Vector databases such as Pinecone, ChromaDB, and Weaviate
  • Chunking strategies and retrieval pipelines
  • Re-ranking and high-precision search
  • Hierarchical chunking, semantic routing, and query expansion
Module 4: Open-source models, quantization, and fine-tuning

Learners work with the open-source AI ecosystem and learn how to adapt models for specific use cases while managing compute constraints and training budgets.

  • Hugging Face tools and model workflows
  • Quantization for reduced memory use
  • LoRA, QLoRA, PEFT, and adapter training
  • Local open-source model inference and GPU memory management
  • Fine-tuning workflows, instruction tuning, and preference alignment
  • Alignment techniques such as preference-based tuning
Module 5: Agentic orchestration and MLOps

The final technical module prepares learners for production work. They learn how to package, deploy, monitor, and maintain AI systems in realistic environments.

  • LangChain, LangGraph, and agent design
  • Docker, deployment, and cloud workflows
  • Monitoring, telemetry, and cost awareness
  • CI/CD practices for AI applications
  • Kubernetes basics, experiment tracking, and logging

Support, Certification, and Format

The training is designed as a guided experience from start to finish. Learners get structure, materials, follow-up, and a certificate once they complete the required work.

Format

Personalized 1:1 sessions

Sessions are scheduled weekly and tailored to the learner’s pace, background, and goals. The pace can slow down or speed up depending on the material.

Materials

Resources and practice support

Learners receive supporting materials, demos, and practice assignments to reinforce each week’s topic and help them continue learning between sessions.

After completion

Post-course guidance

Graduates receive follow-up support after the course and can continue to get help with project troubleshooting or next-step guidance as they apply AI in the real world.

Important: The program does not force students to finish on a rigid timetable. It is designed so the learner leaves confident, capable, and ready to apply what they learned.
